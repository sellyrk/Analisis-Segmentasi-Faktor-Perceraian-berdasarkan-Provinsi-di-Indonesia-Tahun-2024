# Analisis-Segmentasi-Faktor-Perceraian-berdasarkan-Provinsi-di-Indonesia-Tahun-2024
Ini adalah proyek analisis segmentasi pada data perceraian di seluruh Provinsi di Indonesia Tahun 2024 yang kelompok saya buat sebagai proyek akhir pada mata kuliah Machine Learning I

Hasil laporan analisis ditulis dalam bentuk artikel yang telah terpublikasi di Indonesian Journal on Data Science, yang dapat diakses pada tautan berikut: https://ejournal.unjaya.ac.id/index.php/ijds/article/view/1654
